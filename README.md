# Landing Page NaraTech

Landing page institucional da NaraTech Soluções em Tecnologia. Site estático: `index.html` + `assets/`, sem build.

## Antes de publicar

- Trocar `55SEUNUMERO` pelo número do WhatsApp (formato `55DDDNUMERO`) nos links `wa.me`.
- Preencher `[SEU WHATSAPP]` e `[SEU E-MAIL]` no rodapé.

## Publicar no GitHub Pages

Settings > Pages > Deploy from a branch > `main` / `(root)`.

## Identidade

- Cores: tinta `#0B1220`, lavanda `#B6CAF3`, azul NaraTech `#294BA3`, névoa `#F4F6FB`
- Fontes: Lato (títulos) e Inter (texto), via Google Fonts
- Logos em `assets/` (versão preta para fundos claros, branca para fundos escuros)
